主题编辑器配置
1. AH Announcement：可编辑滚动信息和第二行文字。未复制参考站“4.8/5、70,000+ reviews”、79 美元包邮、30 天保证或 24 小时发货承诺。
2. AH Banner slideshow：第一张“Upgrade Your Day, Every Day”图片默认启用。第二张参考图包含“60% OFF”宣传，已内置但默认关闭。核实实际促销后再启用，或上传自己的桌面/手机图。可新增多张图、设置点击链接、手动切换或开启自动播放。
3. 四个 AH Product carousel 区：Products in display order 已按参考顺序选好本店商品。可更换或排序；清空 Products 后会使用所选 Collection 的商品。
4. 每区 View all 默认指向本店全部商品。选择真实集合后可自动改为集合地址，也可在 View all link 中单独覆盖。后台尚无 Best Seller/Toys/Home/Automobile 等集合时，主题不会自动创建。
5. 页头 Header → Use reference navigation 默认开启。导航依次为 Home、Best Seller、Toys、Home、Automobile、Frequently Buy Together。优先使用同名 handle 的集合，缺失时回退到本店搜索/全部商品，不跳往参考店铺或不存在的集合。Reference navigation menu override 可选择自己的实际菜单。关闭参考导航会恢复原 main-menu。
6. 对比表：品牌已改为 One Homa，数值保留破折号。请根据可验证信息填写；未复制参考站关于其他卖家、独家销售、包退和物流的未经核实描述。
7. 服务区：保留本店原有中性说明、政策链接与客服入口。请核实链接有效性，再根据实际政策改写包邮门槛、退款期限或客服时段。
8. AH Green footer：选择真实的 Information 与 Customer Service 菜单。Information 未选时尝试 foot-menu，找不到则显示 Shop all/Search；Customer Service 未选时显示本店已发布政策。
9. 页脚 Contact Us 读取本店名称与店铺邮箱；公司信息可在编辑器填写，未复制 Ahlwo 的公司名、地址和邮箱。支付图标来自本店实际启用的支付方式。
10. 全局 One Homa reference style → Use reference Helvetica/Arial font 控制参考系统字体。Logo 保留本店配置，没有替换为 Ahlwo 标志。
