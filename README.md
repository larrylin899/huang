# Fasamia 首页主题包

基于 Fasamia 导出的 Shopify Horizon 4.1.4 主题，按提供的首页截图制作。

## 下载

点击 [下载主题 ZIP](https://github.com/larrylin899/huang/raw/refs/heads/main/Fasamia-Reference-Homepage.zip)。

如果浏览器显示文件页面，点击 **Download raw file** 下载该文件。

请下载 `Fasamia-Reference-Homepage.zip` 本身，不要使用 GitHub 的 Code → Download ZIP；后者是仓库打包，不能直接当作 Shopify 主题上传。

## 安装与限制

在 Shopify「在线商店 → 主题 → 添加主题 → 上传 ZIP 文件」上传，先作为未发布主题预览。

详见 [安装说明](安装说明.txt) 和 [检查结果](检查结果.txt)。

横幅使用占位图，需要上传有使用权的图片；商品集合和导航需在后台配置。商品详情页保留原版。未连接 Shopify 进行实际渲染或交易流程验证，未修改线上店铺。
